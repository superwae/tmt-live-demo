# TMT live demo

An interactive, self-contained demo of TMT, the crisis coordination platform built with Birzeit
University: the operations console, the citizen app and the ambulance crew app, with live
simulated cases and guided tours. Arabic and English.

Open `index.html`. Everything runs in the browser; nothing is sent anywhere. Places are real
(Ramallah & Al-Bireh); every person, report and figure is invented.

Map data © OpenStreetMap contributors (ODbL).
